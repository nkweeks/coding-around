# Character Asset Mapping

The 3D GLBs are generated from the existing 2D character art, not generic robot or ninja silhouettes.

## BYTE

Primary references:
- `images/robot_happy.jpg`
- `images/robot_angry.jpg`
- `images/ninja_robot_fight_begins.jpg`

Mapped traits:
- Oversized rounded TV head
- Twin ball antennae and round side ear housings
- Large circular cyan eyes with metal rings
- Cyan segmented smile
- Purple shell with bright violet bevels
- Chest panel with slider, status lights, and gear
- Spring/tube neck
- Chunky mitten hands, large boots, cyan trim bands
